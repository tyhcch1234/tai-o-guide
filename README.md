# 大澳 Tai O · 香港最後的水上漁村

一個關於大澳的單頁深度導覽網站：棚屋水鄉、漁鹽歷史、廟宇古蹟、虎山日落，以及蝦醬、鹹魚、沙翁等地道美食，附交通方式與一日遊路線。

## 內容結構

| 章節 | 內容 |
| --- | --- |
| 01 水鄉 | 大澳的地理、棚屋與水上人生活 |
| 02 歷史 | 由宋代鹽業到 2011 年非遺的時間軸（12 個節點） |
| 03 景點 | 10 個地點：棚屋、兩道橋、文物酒店、虎山、關帝廟、楊侯古廟、海味街、天后廟、紅樹林 |
| 04 美食 | 蝦醬蝦膏專題 + 8 款地道食物 |
| 05 行程 | 10:30–18:00 一日遊路線、三種交通方式、旅遊貼士 |

## 技術

- 純靜態 HTML / CSS / JavaScript，無建置步驟、無框架
- 響應式排版（手機、平板、桌面）
- IntersectionObserver 進場動畫、閱讀進度條、平滑滾動
- 尊重 `prefers-reduced-motion`
- 圖片來源以 `assets/img/credits.json` 動態列出

## 本機預覽

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```
